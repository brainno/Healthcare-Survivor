# Healthcare Survivor 설계 문서

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 서바이버류 로그라이트 (Vampire Survivors 계열: 자동 공격, 이동만 조작, 레벨업 시 3택 1) |
| 모티프 | 인체 면역체계 및 의학적 치료수단 |
| 목표 | 10분간 생존 |
| 교육 목표 | 치료수단의 **작용 표적**과 병원체의 **생물학적 특성**이 일치해야 효과가 있다는 원리를 플레이로 체득 |
| 플랫폼 | 웹 브라우저 (HTML5 Canvas, 외부 라이브러리 없음) |

## 2. 핵심 설계 원칙

1. **효능은 기전으로 결정한다.** 각 적은 생물학적 특성 태그(예: `gram_pos`, `outer_membrane`, `ergosterol`, `pbp2a`)를 가지며, 각 치료수단은 "어떤 태그가 있으면 얼마나 듣는가"라는 규칙 목록을 가진다. 표적이 없으면 피해 배율은 0(무효)이다.
2. **무효에도 이유를 보여준다.** 무효 판정 시 그 이유(예: "펩티도글리칸 세포벽이 없어 표적이 존재하지 않음")를 학습 로그에 기록하고, 게임 종료 시 이번 판에서 확인한 기전 목록을 제공한다.
3. **실제 치료의 대가(trade-off)를 규칙으로 옮긴다.** 약물 독성, 항생제 내성, 면역억제, 골수억제, 면역관문 억제제의 자가면역 부작용을 게임 시스템으로 구현하였다.
4. **수치는 추상화임을 명시한다.** 피해량·주기·배율은 게임 밸런스용이며 임상 용량이나 효과 크기를 의미하지 않는다.

## 3. 게임 시스템과 생리학적 근거

| 게임 시스템 | 구현 | 근거가 되는 실제 현상 |
|---|---|---|
| 효능 배율 | 무기 규칙 × 적 태그 → 배율 0~2 | 약물·면역 효과기의 분자 표적 특이성 |
| 이분법 증식 | 세균·진균·암세포가 주기적으로 분열 | 세균 이분법, 종양세포의 무제한 증식 |
| 로지스틱 증식 | 개체 수가 수용력에 가까울수록 분열 확률 감소 | 영양·공간 제한에 의한 개체군 성장 둔화 |
| 바이러스 복제 | 인플루엔자가 주기적으로 2개체 방출 | 숙주세포 내 복제 후 방출 |
| 방출 차단 | 오셀타미비르 명중 시 일정 시간 복제 중단 | 뉴라미니데이스 억제제는 감염세포에서 바이러스 방출을 막음 |
| 항생제 선택압 | 항생제 계열별로 세균 처치 수가 누적 → 신규 세균이 내성 태그를 가질 확률 증가, 분열 시 딸세포에 유전 | 항생제 노출이 내성 균주를 선택하고 증식시키는 현상 (WHO) |
| 항생제 관리 프로그램 | 선택압 누적 감소 | 항생제 스튜어드십 |
| 약물 독성 | 약물 사용 시 누적, 간·신장 청소로 감소, 60 초과 시 생명력 감소 | 약물 대사·배설 용량을 넘는 투여의 장기 독성 |
| 골수억제 | 시스플라틴 사용 후 면역세포 무기 위력 60%로 감소 | 세포독성 항암제의 조혈세포 손상 |
| 면역억제 | 프레드니솔론 사용 후 면역세포 무기 위력 65%로 감소 | 글루코코르티코이드의 광범위 면역 억제 |
| 옵소닌화 | IgG 항체 명중 대상은 4초간 받는 피해 +30% | 항체·보체의 옵소닌화에 의한 탐식 촉진 |
| 면역기억 | 같은 병원체 처치 수에 비례하여 면역세포 무기 피해 증가(최대 +50%) | 기억 B·T세포에 의한 2차 면역반응 |
| 백신 | 인플루엔자 면역기억 즉시 최대 | 예방접종에 의한 사전 기억세포 형성 |
| 면역관문 | 암세포(PD-L1)에 대한 T세포 무기 피해 25%로 감소, 항PD-1 획득 시 해제되나 자가반응성 T세포 출현 증가 | PD-1/PD-L1 경로, 면역 관련 이상반응(irAE) |
| 자가면역 관해 | 자가반응성 T세포는 40초 후 소멸 | 재발-관해 경과의 단순화 (추상화 수준 높음) |

## 5. 코드 구조

```
index.html          화면 구조 (HUD, 레벨업, 일시정지·도감, 결과)
css/style.css       스타일
js/data.js          적·무기·패시브 데이터, 효능 판정 함수 efficacy(), 출현표 — 게임 규칙의 단일 출처
js/ui.js            HUD, 레벨업 카드(효능 요약 포함), 도감, 결과 화면
js/game.js          게임 루프, 이동, 무기 발사 패턴, 증식·내성·독성 시뮬레이션, 렌더링
tests/efficacy.test.js  효능 규칙이 기전과 일치하는지 검증하는 단위 테스트
```

새 적이나 치료수단을 추가할 때는 `js/data.js`에 태그와 규칙만 추가하면 된다. 규칙의 `note`에 기전 설명을 적으면 게임 내 학습 로그에 자동 표시된다.

## 6. 전문가 검토가 필요한 항목

아래는 게임성을 위해 단순화하였거나 근거 강도가 상대적으로 약한 부분이다. 교육 자료로 사용하기 전 의학·약학 전문가의 검토가 필요하다.

1. **인플루엔자 적의 추상화** — 비리온과 감염세포 군집을 하나의 적으로 표현하였다. NK세포·세포독성 T세포는 실제로 비리온이 아니라 감염세포를 제거한다.
2. **획득 내성의 계열 구분** — 반코마이신 내성 황색포도상구균(VRSA)은 실제로 드물며, 게임의 선택압 모델은 모든 계열에 동일한 규칙을 적용한다. 내성 발생 속도는 실제 역학 자료를 반영하지 않는다.
3. **페니실린의 그람음성균 효능(0.4)** — 페니실린 G 기준의 단순화이다. 아미노페니실린(암피실린·아목시실린)은 일부 그람음성균에 작용한다.
4. **클라불란산과 β-락타마제** — 클라불란산은 모든 β-락타마제를 억제하지 않는다(예: AmpC, 카바페네메이스). 게임에서는 억제 가능한 효소를 가진 균주로 한정하여 설명하였다.
5. **메스의 세균 효능** — 농양 절개 배농을 단순화한 것이며 일반 감염을 수술로 치료한다는 의미가 아니다.
6. **시스플라틴의 세균 효능(0.4)** — 백금 화합물의 대장균 분열 억제 관찰(Rosenberg 1965)에 근거하나 임상적 항균제가 아니다.
7. **면역세포별 배율** — 호중구·대식세포·NK세포의 병원체별 상대 기여도는 감염 부위와 병기에 따라 다르며 정량적 근거가 아니다.
