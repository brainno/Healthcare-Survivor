# Healthcare-Survivor

인체 면역체계를 모티프로 한 서바이버류(Vampire Survivors 계열) 로그라이트 교육용 게임입니다.
적은 세균·바이러스·진균·기생충·암·자가면역이며, 플레이어는 면역세포·약물·수술·방사선 치료를 조합해 10분간 생존합니다.
각 치료수단은 **실제 작용기전**에 따라 특정 병원체에만 효과가 있습니다(예: 페니실린은 MRSA와 바이러스에 무효).

## 실행

별도 설치나 빌드가 필요 없습니다.

- `index.html`을 브라우저로 직접 열기, 또는
- 로컬 서버: `npm start` 후 http://localhost:8080

조작: WASD/방향키(모바일은 화면 드래그)로 이동, 공격은 자동, ESC/P로 일시정지 및 도감, 레벨업 카드는 1/2/3 키 또는 클릭.

## 주요 시스템

- 기전 기반 효능 판정 및 "무효" 이유 표시, 학습 로그
- 항생제 선택압에 따른 내성균 출현과 유전
- 약물 독성·청소율, 골수억제, 스테로이드 면역억제
- 옵소닌화, 면역기억, 백신, 면역관문(PD-L1)과 항PD-1 부작용
- 게임 종료 시 이번 판에서 확인한 작용기전 목록

상세 설계, 생리학적 근거, 전문가 검토 필요 항목, 참고문헌은 [docs/DESIGN.md](docs/DESIGN.md)를 참조하십시오.

## 테스트

```
npm test
```

효능 규칙이 작용기전과 일치하는지(예: 반코마이신은 그람음성균에 무효, 클라불란산은 MRSA에 무효) 검증합니다.

## 주의

게임 내 수치는 밸런스를 위한 추상화이며 실제 임상 효과·용량을 의미하지 않습니다. 의학적 판단에 사용하지 마십시오.
